All Orders · banner · phase one

The dial, drawn

The renderer is built and every state is on this page at true 280 × 121, sitting on the real black band. Nothing has touched the sheet. You look first — that was the rule this build exists to follow.

The five states

One verdict cell drives all of it — __SparkData!A6, the same cell the current face reads. The dial shows what matters in that state and nothing else: the clock when there is nothing to act on, the wait as a shape when there is.

Rest — 9:57 PM, floor closed

The ring wears yesterday, one mark per worked hour. Cool grey throughout so the loudest place on the screen never raises an alarm nobody can answer — with the single warm point on the one live number, the countdown to nine.

Clear — 1:05 PM, queue empty

The arc traces nine to five along the path the hands actually travel, filled to now, bright head on the leading edge. Deliberately green rather than brand yellow: yellow means act everywhere else on this sheet, and an empty queue asks for nothing.

Busy — 2:14 PM, twelve to grab

One hand is now. The other points at when the oldest open order landed. The wedge between them is the wait — the only duration on this sheet, and the only number that costs money as it grows.

Late — three past the 3h line

Same instrument, warm red, and the wedge has opened to a right angle. You read lateness as a shape from across the desk instead of comparing two numbers. Third row swaps to the past-the-line count.

Stale — nothing logged for 1h 13m

A different red from late, because it is a different problem: the orders are fine, the pipeline is not. The floor's own counts stay visible — a dead sync does not make the work disappear, it means nobody can trust the count.

Does it move?

You asked, so here is the evidence rather than the argument. On the sheet the ceiling is one frame a minute — formula recalc, measured, not guessed. The film below is every frame the banner will actually draw between 8:40 and 5:40, in order, nothing interpolated. Nine hours in fourteen seconds.

The honest half

Compressed, it looks alive. Lived at real speed it is a clock, not an animation — it reads as alive the way a wall clock does, because you catch it in a different position, not because you watched it move.

Which is why the design has no second hand. Anything that should sweep would instead twitch once a minute and read as broken. What does change is the thing worth watching: the wedge opens, the arc fills, the pips accumulate, the colour escalates.

Three routes to real motion

An animated GIF in the cell

=IMAGE() renders a GIF's first frame and never advances it. Proven twice with a known-good file. This one is closed.

Dead end

A floating image over the banner

insertImage() does animate — that part is proven. But a floating image anchors to a cell, not the viewport, so it slides off the frozen banner the moment you scroll. That, and only that, is what rules it out. It is also the one measurement worth re-taking: the same note once read “a Sheet cannot animate”, concluded from the line above, and you were right to push back on it. The probe is written — anchored inside the frozen region this time, which has never actually been tested here. Thirty seconds, writes no cells, removes itself.

Worth one test

The same dial, on a surface that can move

The drawing module is plain canvas — it already runs unchanged in a browser. The Floor Board and the wall could carry this exact instrument at sixty frames a second, hands sweeping, for no new drawing code at all. One module, three surfaces. That is also this project's own long-standing ruling about where smooth motion belongs, and the dial just made it nearly free.

Free, once built

On busy the flank reads “12 to grab / 14 out today” and D1 reads “12 to grab / 14 in · 14 out”, 200px apart. On stale the same duration appears three times — dial, D1, pulse. What looking at it caught

Three things that a code review would not have found, and one of them was already shipping.

Bug · tofu

The clock rendered as four empty boxes

The font library reports Oswald ExtraLight as weight 250 and then fails to match it when you ask for 250 — measureText("9:57") comes back 600px instead of 29px, silently. Same shape as the ⛶ and 📻 tofu the Floor Board hit on the real tablet. There is now a boot probe that refuses to stay quiet about it.

Design · collision

The shift arc and the wait wedge fought each other

Both are accent-coloured curves on a 103px face, drawn concentrically. At 4× they looked fine; at true size they fused into one orange smear. They now take turns — the arc yields whenever there is a wait, because a duration is worth more than a progress bar.

Design · overlap

The hands buried the newest thing on the ring

The now-hand always points at the current hour, which is always where the newest pip sits — so full-length hands permanently hid the most recent thing the day's record had to say. The hands stop short now: outer ring is the day so far, inner zone is the wait, and they never cross.

Build order

The plan's four phases. Only phase three touches the sheet, and putting the face back is one formula at any point.

1 Draw it hereOne module, two hosts — this machine and the container. 42 assertions, three mutations proven to fail. Done
2 The containerNode + the canvas binding + the Oswald files, on the existing compose stack. Then one Caddy route — the highest blast-radius file on the VPS, restarted not reloaded. Next
3 The sheetOne =IMAGE() in a merged A1:C2, row 2's logo zone shrinks to D2:E2, the face formula retires. The art stays on the server for a week. Waiting
4 VerifyThe per-minute refresh is the one real unknown — and a missing route answers 200 with the board's HTML, so the check has to read content type, not status. Waiting
