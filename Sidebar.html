Pull from Zoho

▼
Type the Zoho SO # (e.g. SO-22815) or invoice # (e.g. INV-022496). Preview gives a quick summary — customer, totals, status, price-check verdict. Pull opens the review modal where you confirm the line items and apply them to the DIRECT table. Kit Expansion

▼
Select kit rows in All Orders → Expand Selected → opens a popup modal with the Sales Description reference, per-component exclusion, and a per-kit Spares input, then commits from there. Spares for us is additive: 0 ships exactly the customer's row qty; N adds N extra kits per row. READY kits (K-* aisle) and already-expanded kits are refused with a reason.

Kit Pricing

▼
Price a new kit before listing, or re-check an existing one: Σ(component price × qty) × (1 − discount), rounded to the nearest dollar. eBay is the price source; unpriced parts are flagged, never guessed. Pick an existing kit or paste a BOM. Decision-support only — nothing is written.

Prep Queue

▼
⚡ Quick Add
📍 Loc —
◫ Hand —
Three tables: CURRENT on top, INCOMING (future prep) below the yellow divider, then NEEDS PHOTOS at the bottom (auto — every ACTIVE listing still at 0–1 images, i.e. only the logo). The current table grows on its own — type in the blank rows and the divider slides down. Sort re-orders each table by location and closes gaps (checkmarks survive). Tick a row's ✔ box to strike it through; Clear Done sweeps ticked rows from CURRENT + INCOMING only. The NEEDS PHOTOS table is machine-owned — it self-cleans hourly as real photos land in MI; tick ✔ to mark "shot it, pending upload" (that survives). Locations + photo needs re-mirror hourly — the ⟳ chip shows the last refresh.

Out of Stock

▼
Two tables: restock list on top (Active listings at zero or below), OOS KITS below the yellow divider with a live BUILDABLE count from components. Sort re-orders each table on demand (restock by location, kits by buildable). Auto-refreshes hourly during work hours (6am–6pm Houston) — the ⟳ chip on the sheet shows the last refresh. A row shown struck-through gray with "⟳ Zoho: N" means Zoho already sees stock — Master Inventory just hasn't caught up yet (drops within the hour).

Price Audit

▼
Compares Zoho selling_price vs eBay currentPrice (MI) across all items. Surfaces drifts so admin can fix Zoho before quotes.
To fix: highlight drift rows on the sheet → Push Highlighted → review/uncheck in the modal → passphrase → applies eBay price to Zoho (selling + cost). Re-run the audit to confirm.
More tools
First run needs MI's currentPrice populated. OOS items (eBay returns null Price) classify as NO REF and are skipped — reported in summary, not written as drifts.

Kit Health

▼
One row per kit: computed price (Σ parts × 0.9) vs its listed price, plus how many you can build now from component stock. UNDERPRICED kits sort to the top; the DISC % column separates an intentional discount from a stale-part money leak. Reuses the pricing + buildable engines — decision-support only, nothing written.
More tools
Needs the Kit Registry imported + MI currentPrice populated. Kits with unparsed PD or unpriced parts show ⚠ INCOMPLETE (computed left blank — never a wrong number) and park at the bottom. A weekly Mon ~4am auto-run needs a one-time setupKitHealthTrigger() from the editor.
☰

Weekly Digest

▼
More tools
Monday ~8am ops digest → the admin Telegram chat: underpriced kits (+$), buildable-now, in-stock-blocked, OOS, open cases, price drift. Preview shows the exact text without sending; Send now posts it; Arm weekly installs the Monday schedule. Reads the last Kit Health / Price Audit run — decision-support only.

Straggler Watchdog

▼
More tools
Pushes to the admin Telegram chat, hourly, during work hours: orders past the 3h line, SOs part-shipped over 24h, and kits sitting unexpanded in DIRECT.

Each item alerts once, when it first crosses — it never repeats, so it stays worth reading. Preview shows everything currently late without sending or recording anything. Reset forgets what's been said, so the next run re-arms and re-seeds.

Location Update

▼
Fetch asks eBay LIVE for every row's location and paints the verdict in ◉ EBAY LOC: green = matches the typed LOCATION · red = disagrees (or blank on eBay) · gray = SKU not on eBay / check failed. Type SKU → timestamp auto-stamps + SKU links to its listing. LOCATION stays manually edited.
More tools
